Full name Staff needs a way to address the person for the plot Yes input type="text" name name Up to 80 characters, inside the help text, any format is accepted. a single field instead of first/last so that all name formats work. this is a perosnal identifier.

Phone number (optional) If they dont like the email they can instead use the phone number as a backup contact. No input type="tel" phone tel Example 480-234-6589 shown. There is no pattern so any phone format can work. Personal contact. This is optional.
ZIP code Confirms the person is a resident of Mesa. Yes input type="text" zip postal-code / inputmode="numeric" Exactly 5 digits like 23463. It will only require the zip, so no street address collected.
